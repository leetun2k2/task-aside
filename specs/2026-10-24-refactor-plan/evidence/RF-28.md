# RF-28 — Introduce accessible UI primitives

## Outcome
- Installed `@radix-ui/react-dialog@1.3.1`, `@radix-ui/react-dropdown-menu@2.2.1`, and `@radix-ui/react-tooltip@1.4.1`.
- Built shared accessible UI primitives under `src/frontend/components/ui/`:
  - `Dialog`: Accessible modal primitives supporting keyboard focus trap, ESC handling, and overlay management.
  - `DropdownMenu`: Accessible popover / dropdown menu primitives with arrow navigation and focus restore.
  - `Tooltip`: Accessible tooltip primitives with portal rendering and screen reader announcement.
  - `Button`: Standard button with semantic variants (`primary`, `secondary`, `danger`, `ghost`), sizes (`sm`, `md`, `lg`), loading spinner, and `:focus-visible` accessible outline.
  - `Badge`: Accessible badge components for task priority (`PriorityBadge`) and lifecycle status (`StatusBadge`).
- Exported all primitives via `src/frontend/components/ui/index.ts`.

- `bun run test:ui`: Passed all UI and integration checks.
- `bun run test:browser`: Passed headless Chrome CDP browser interaction suite.
- `bun run test:workflow`: Passed live workflow checks.
