# RF-25 — Preserve task drafts and HITL behavior

## Outcome
- Draft preservation: tracked drafts per task (`draftsByTask`) in view state. Navigating across tasks restores each task's in-progress text draft.
- Task status transitions (such as entering `processing` or `hitl`) do not wipe the composer's draft text.
- Clean submission: only successfully submitted content is cleared from the draft. If the user continues typing while a send is in-flight, the additional text prefix is preserved.
- Send failure recovery: if a message send fails or is rejected, the draft remains intact in the textarea for easy retry or editing.
- HITL banner: accurately shows input required prompt and handles stale reply rejection (`REQUEST_ALREADY_RESOLVED`) with actionable guidance without clearing user input.
