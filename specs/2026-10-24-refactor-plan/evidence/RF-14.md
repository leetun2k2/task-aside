# Evidence: RF-14 — Replace unsafe Markdown rendering

## Outcome
- Removed `marked` and replaced regex-based HTML injection in `src/frontend/components/MarkdownView.tsx` with native `react-markdown` (`10.1.0`) and `remark-gfm` (`4.0.1`).
- Completely disabled raw HTML parsing (no `rehype-raw` plugin). All raw HTML tags (e.g. `<script>`, `<span>`, `<img onerror="...">`) are treated strictly as plain text.
- Replaced remote `<img>` rendering with safe text placeholder badges (`🖼️ [alt] (src)`) to eliminate unsolicited external image fetches and tracking vectors.
- Enforced safe URI schemes on links: only `http:`, `https:`, and internal hash `#` links are rendered with `target="_blank" rel="noopener noreferrer"`; dangerous schemes (`javascript:`, `data:`, `vbscript:`) are neutralized into inert spans.
- Verified in headless Chrome CDP interaction checks: confirmed that raw HTML probe elements are no longer created in the DOM, converting the previous regression to a clean pass.
