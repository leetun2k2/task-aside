# RF-18 — Cache task and repository reads

## Outcome
- Installed `@tanstack/react-query@5.104.5`.
- Created `src/frontend/queries.ts` establishing `queryKeys` for tasks, repositories, messages, and settings.
- Configured `QueryClient` with explicit `staleTime: 5000` (5s freshness), `gcTime: 5 * 60 * 1000` (5 min cache boundary), focus-refetch enabled, and retry logic omitting fatal 502 malformed response failures.
- Integrated `QueryClientProvider` and `useQuery` into `src/frontend/App.tsx` for tasks and repositories.
- Connected SSE event handlers and user actions (create, edit, cancel, retry, add repository) to authoritative TanStack Query cache updates via `queryClient.setQueryData` and invalidations.
- Retained search, grouping, and task selection preferences cleanly in view state while preserving backend list ordering.
