# Evidence: RF-06 — Record reproducible performance baseline

## Outcome
- Built repeatable seeded benchmark runner in `src/benchmarks/performance-baseline.ts`.
- Seeded disposable datasets: 1,000 tasks / 500 messages, scaled to 10,000 tasks / 5,000 messages, with 8 active concurrent runs across 8 distinct registered checkout directories.
- Recorded artifact sizes, transfer sizes, query latencies (p50/p95), claim latencies, and process RSS memory.
- Kept all benchmark utilities inside `src/benchmarks/` to ensure zero footprint in production runtime packages.

## Baseline Measurements

### 1. Artifact & Build Sizes
- **Frontend JS:** 226.30 KB raw (231,728 bytes) / 69.45 KB gzip (71,112 bytes)
- **Frontend CSS:** 21.89 KB raw (22,413 bytes) / 4.63 KB gzip (4,745 bytes)
- **Backend Service Bundle:** 331.22 KB (339,169 bytes)
- **Agent Adapter Service Bundle:** 270.97 KB (277,474 bytes)
- **Execution Engine Service Bundle:** 268.68 KB (275,124 bytes)
- **CLI Entrypoint Bundle:** 12.21 KB (12,507 bytes)

### 2. Dataset Seeding & Ingestion Timings
- **1,000 Tasks + 500 Messages:** 38.78ms (transactional batch)
- **Scale to 10,000 Tasks + 5,000 Messages:** 363.18ms (transactional batch)

### 3. Backend Query Latencies (Cold / Warm p50 & p95)
- **1,000 Tasks List Query (`status='todo'`, `priority='P1'`):**
  - p50: **0.272ms**
  - p95: **0.709ms**
- **500 Messages Forward Cursor Page Query (`limit=50`):**
  - p50: **0.040ms**
  - p95: **0.061ms**
- **10,000 Tasks Substring Search Query (`LIKE '%scale benchmark%'`):**
  - p50: **9.472ms**
  - p95: **13.070ms**
  - *Note:* Substring LIKE query scales linearly with row count; candidate for indexed or paginated tuning in R5.
- **5,000 Messages Cursor Page Query (`limit=50`):**
  - p50: **0.042ms**
  - p95: **0.051ms**

### 4. Working-Tree Lock & Claim Latencies (8 Concurrent Checkouts)
- **Claim Latency per Tree:**
  - p50: **0.127ms**
  - p95: **2.664ms**
  - Verified atomic claim, generation increment, and lock acquisition across 8 distinct repositories with zero collision.

### 5. Memory Footprint (Seeded 10k dataset in-process)
- **RSS Memory:** 93.22 MB
- **Heap Used:** 23.66 MB
- **Heap Total:** 33.88 MB
