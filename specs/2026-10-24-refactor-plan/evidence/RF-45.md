# RF-45 Verification Evidence: Simplify adapter lifecycle callbacks

## 1. Outcome
- Replaced nested anonymous callbacks in `AdapterRunManager` with discrete, named lifecycle handlers:
  - `handleDriverEvent(run, event)`: forwards events to stream publisher and log writer.
  - `handleDriverEnd(run)`: handles clean completion, clears deadline timers, updates status to `done` with `process_group_empty` proof, and notifies subscribers.
  - `handleDriverError(run, err)`: handles process failure, updates status to `error`, emits failed event envelope, and notifies subscribers.
  - `handleDriverSessionId(run, sid)`: binds session id to run for resume capability.
  - `bindDriverCallbacks(run)`: creates bound `DriverCallbacks` contract.
- Extracted shared process-group termination and verified-stop verification into `src/agent-adapter/drivers/process-group.ts` (`terminateProcessGroup`).
- Refactored `CodexDriver.cancel` and `ClaudeDriver.cancel` to reuse `terminateProcessGroup` with two-stage SIGTERM -> wait ESRCH -> SIGKILL -> wait ESRCH progression and honest `process_group_empty` proof.
- Preserved distinct driver characteristics: Codex `exec` non-resume baseline vs. Claude `-p --session-id / --resume` multi-turn sessions.
