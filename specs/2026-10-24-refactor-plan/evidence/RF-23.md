# RF-23 — Reconcile reconnects and task versions

## Outcome
- Enforced task version monotonicity in the browser SSE event listener: events with a version lower than the currently held task version are discarded, preventing stale events or out-of-order networks from rolling task state backward.
- Implemented explicit null clearing: nullable fields (`blockedReason`, `blockKind`) clear explicitly when `'blockedReason' in payload` is null, rather than falling back to stale values via `??`.
- Added missing task detection: if an event arrives for a task not present in the local task cache, a targeted invalidation of `queryKeys.tasks()` is triggered to fetch the new task row.
- Reconnection backoff: replaced flat reconnection loop with exponential backoff and jitter bounded between 1s and 10s, preventing request storms on backend restarts or dropped connections.
