### Task Ordering & Chat Cursor Direction
- **Runnable Task Queue:** Priority (`P0` < `P1` < `P2` < `P3`), tie-broken by `enqueued_at` ascending.
- **Chat Messages:** Forward cursor pagination with `nextCursor`. Ordered chronologically by `created_at` / `sequence` ascending. Default page size: 50, maximum: 200.

### Event Projection & Invariants
- `EventHub` in `src/backend/events/hub.ts` operates strictly in-memory. Monotonically increasing sequence ID per server session.
- SSE broadcast over `/api/events` protected by Bearer token; internal tokens are rejected with 403.
- Event deduplication via `run_event_receipts(run_id, sequence)` database table prevents duplicate ingestion.
- Lock release requires verified stop evidence (`verifiedStopped: true` with valid `verificationMethod`).
