# RF-26 — Bound stream rendering and scrolling

## Outcome
- Delta Batching: Introduced a 50ms bounded delta flush buffer in `src/frontend/App.tsx`. High-frequency token bursts are batched to prevent render churn while completions and task switches trigger an immediate flush.
- Markdown Memoization: Wrapped `MarkdownView` with `React.memo` so completed messages are not reparsed during active streaming.
- Reader-Aware Scrolling: Detected scroll position in `src/frontend/components/TaskConversation.tsx`. Auto-scrolling only follows the bottom when the user is already at the bottom (`isAtBottomRef`). Scrolled-up readers stay in place without being yanked down.
- Follow-Latest Control: Added an explicit "Jump to latest" button when the reader is scrolled up and new content arrives.
- Accessibility / Reduced-Motion: Honored `prefers-reduced-motion` media query using instant `auto` scroll behavior instead of `smooth`.
